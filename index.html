FAQ

How do I order?

Open a course and use the WhatsApp order button. Replace the placeholder WhatsApp number in the Admin Panel.

Can I create sales?

Yes. Admin can enable a sale and set either a sale price or a percentage discount.

Can I add future courses?

Yes. Admin can add future/external courses without changing the source code.

Will admin changes automatically appear for every visitor?

This is a static GitHub Pages website. Browser-local admin changes are stored in that browser only. For shared live changes across all visitors, a backend/database is required.
